# QA Functional Testing Portfolio

## BankingApp

Personal QA portfolio project focused on Functional Testing and Software Quality Assurance.

The project demonstrates the complete testing process, from requirements analysis and test case design to defect reporting, SQL data validation, API testing, regression testing and final test reporting.

## Objective

Demonstrate practical knowledge of:

- Functional Testing
- Test Case Design
- Requirements Analysis
- User Stories
- Acceptance Criteria
- Bug Reporting
- SQL Testing
- API Testing
- Regression Testing
- Agile / JIRA concepts

## Application

BankingApp is a simulated banking application designed for educational and portfolio purposes.

### Main Modules

- Login
- Dashboard
- Accounts
- Transactions
- Transfers
- Beneficiaries
- Logout

## Testing Activities

The project includes:

1. Requirements analysis
2. Test planning
3. Test case design
4. Test execution
5. Defect reporting
6. SQL validation
7. API testing
8. Regression testing
9. Final test report
